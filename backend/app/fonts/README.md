# Bundled fonts

These fonts are used to render complex scripts (Indic) whose conjuncts and
vowel signs cannot be shaped by the standard PDF fonts.

| File | Used for |
| --- | --- |
| `NotoSans-Regular.ttf` | Latin fallback inside shaped names |
| `NotoSansDevanagari-Regular.ttf` | Devanagari (Hindi, Marathi, Sanskrit, …) |
| `NotoSansMalayalam-Regular.ttf` | Malayalam |
| `NotoSansTamil-Regular.ttf` | Tamil |

Source: <https://github.com/notofonts/noto-fonts> (hinted TTF builds).
